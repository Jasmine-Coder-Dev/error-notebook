# 错题集 App · 全流程测试方案

> 版本：v1.1　日期：2026-10-12
> 适用版本：v0.0.3 及之后（含 SM-2 / 知识图谱 / 液态玻璃 / 大学三级分类）
> 测试视角：**模拟真实用户操作**（非程序员：家长、中小学生、大学生、考证人员）
> 通过标准：每条用例按步骤操作后"预期结果"全部成立，且无报错弹窗、无控制台红错

---

## 一、测试环境准备

| 项目 | 要求 |
| --- | --- |
| 设备 | macOS（Apple 芯片）本机 + Windows 11 各一台 |
| 测试数据 | ① 真实文本型 PDF 试卷 1 份（带 1./(1)/第1题 混合题号）② .docx 试卷 1 份 ③ 手机拍摄的试卷照片 1 张（清晰、含 3 题以上）④ 构造图片（截图含文字） |
| AI 配置 | Mock 模式（默认）+ 至少 1 家真实厂商 Key（推荐 deepseek-flash，验证真实链路） |
| 数据准备 | 空库状态 1 次（全新启动）；有 20+ 道错题的状态 1 次（用「加载示例数据」+手动补录） |

## 十一、异常与边界（P1）

| 编号 | 场景 | 预期 |
