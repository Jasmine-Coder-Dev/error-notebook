# 错题集 · 受众扩展可行性方案（v1.0）

> 日期：2026-10-10　状态：设计稿（待确认后实施）
> 目标：把产品从「高中以下学生」扩展到**中小学生、大学生、职业考试人员**（如中级会计师、法考、教资、公务员、考研）。

## 3. 数据模型设计（学段 Stage 模型）

### 3.1 现状与问题

当前 `questions` 表：`grade`（枚举 一年级~高三）、`term`（上/下）、`subject`（9 科）——分类维度与取值都被 K12 绑死；`catalog.json` 只覆盖小学语数英 + 初中数学。

### 3.2 目标模型（向后兼容，一次迁移）

```
questions 表新增：
  stage TEXT NOT NULL DEFAULT ''      -- 学段：小学/初中/高中/大学/职业考试/其他

grade 字段语义升级为「分类一」（不改列名，零迁移成本）：
  小学/初中/高中 → 年级（沿用现有取值）
  大学           → 课程名（高等数学、线性代数、概率论与数理统计、大学英语…支持自由输入）
  职业考试       → 考试项目（中级会计、法考、教资、公务员、考研…支持自由输入）

subject 字段语义为「分类二」：
  K12 → 9 科不变
  大学 → 章节（自由输入 + 常见建议）
  职业考试 → 科目（中级会计实务/财务管理/经济法…按考试项目联动）

term 字段：仅 stage ∈ {小学, 初中, 高中} 时 UI 显示；大学/职业考试隐藏（存空）
```

迁移：`ALTER TABLE questions ADD COLUMN stage TEXT NOT NULL DEFAULT ''` + 按 grade 回填（一~九年级→小学/初中，高一~高三→高中；空 grade 视为其他）；同批新增 `qtype TEXT NOT NULL DEFAULT ''`（题型，见 4.1A，历史数据默认"未分类"，可批量 AI 补标）。旧数据零破坏；导出/导入 JSON 同步带 stage/qtype。

### 3.4 AI 打标适配

`/api/ai/tag` 入参加 `stage`；prompt 按学段变化：
- K12：沿用现有"从年级×学期×科目目录中选"
- 大学：从「课程×章节」目录选，标签粒度=章节知识点
- 职业考试：从「考试项目×科目」目录选，标签粒度=考点（如"长期股权投资"）

### 4.1 统计分析功能设计（一期新增重点）

#### A. 题型统计（新增）

**数据模型**：`questions` 表新增 `qtype TEXT NOT NULL DEFAULT ''`（题型）。题型词表按学段/科目适配：

| 学段 | 题型词表（种子，可自定义扩充） |
| --- | --- |
| 小学 | 选择、填空、判断、计算、应用题、操作作图、口算 |
| 初中/高中 | 选择、填空、判断、计算、应用题、实验探究、作图证明、阅读理解、作文、听力 |
| 大学 | 选择、填空、计算证明、简答、论述、案例分析、翻译、作文 |
| 职业考试 | 单选、多选、判断、不定项选择、计算分析、简答、综合题/案例分析（中级会计等��、申论 |

**题型来源（三级，取先命中者）**：
1. **AI 自动识别**：整卷切分校对（split-check）已有题型猜测能力，升级为落库；单题 AI 打标（tag）同步返回题型
2. **手动指定**：录入预览与错题卡片上题型下拉（词表按当前学段/科目联动）
3. **未识别**：显示"未分类"，统计页单独一档，提示用户补标

**统计展示**（知识点分析页升级为「学情分析」页，两个 tab）：
- **题型 tab**：按当前筛选范围（学段/年级/科目）统计各题型错题次数
  - **柱状图**（默认）：题型 × 错题数，降序排列，一眼看出"应用题错最多"
  - **饼图**（切换）：占比视图，含"未分类"灰色扇区
  - 联动下钻：点击某题型 → 筛出该题型全部错题列表
- **知识点 tab**：保留现有横向条形图 Top10 + 点击针对出题（已上线能力的延续）
- 图表实现：纯 CSS/SVG（延续零依赖路线），饼图用 conic-gradient

#### B. 知识点统计（已有，随一期增强）

现状：按知识点聚合错题次数的横向条形图 + 一键针对出题，已上线。一期增强：
- 统计口径升级：默认只算「未掌握 + 复习中」的错题（已掌握降权），可切换"全部错题"口径——避免老错题长期霸榜
- 掌握状态分布：每个知识点行尾附 微型堆叠条（未掌握/复习中/已掌握 三色），一眼看出"错得多且还没补"的优先目标
- 按学段分组 tab（随 Stage 模型落地）

## 5. UI 设计

### 5.0 设计原则与参考（总纲）

**参考对象**（同类产品与主流桌面应用的共性提取）：

| 参考来源 | 借鉴点 |
| --- | --- |
| Cherry Studio / ChatBox（开源桌面应用） | 左侧栏导航 + 卡片化内容区的桌面信息架构；明暗双主题的变量化管理方式 |
| Things 3 / Notion | 克制用色、大量留白、单一强调色贯穿；操作路径不超过两层 |
| 粉笔 App | 「练习→反馈→再练」的流程闭环设计；考试项目→科目→章节的层级导航 |
| 橙果错题本 | 录入流程步骤化（上传→识别预览→确认入库），每步只做一件事 |
| macOS 26+ / Windows 11 系统应用 | 平台原生材质（液态玻璃 / Mica）、系统字体栈、平台规范圆角 |

**四条硬性要求**：① 界面简洁大方——一屏一个主要任务，无装饰性元素；② 功能明确——每个入口的用途一眼可辨，图标+文字双编码；③ 便于使用——高频操作（录题、组卷）≤2 次点击到达；④ 流程顺畅——多步操作用步骤条引导，每步有明确反馈与回退。

### 5.5 平台原生观感适配

#### macOS（适配 macOS 26+ / 27 液态玻璃 Liquid Glass 风格）

- **窗口层**：启用 Tauri `windowEffects`（`titleBarTransparent` + `fullSizeContentView` + `NSVisualEffectView` 材质 `sidebar`/`underWindowBackground`），标题栏与侧边栏透出桌面级实时模糊
- **面板层（Web 内）**：侧栏与顶栏容器使用「玻璃材质」CSS——`backdrop-filter: blur(24px) saturate(180%)` + 半透明基底（浅色 rgba(250,250,252,0.72) / 深色 rgba(22,27,38,0.68)）+ 1px 内描边高光（浅 `rgba(255,255,255,0.5)` / 深 `rgba(255,255,255,0.08)`），内容滚动时在玻璃层下滑过，形成层次
- **控件**：胶囊形按钮与输入框（圆角 10~12px）；悬浮卡片投影柔和（多层 box-shadow）；图标统一细线风格（1.5px stroke，类 SF Symbols 观感）
- **务实说明**：Liquid Glass 的折射/动态高光是系统原生控件特性，Web 层以「模糊 + 半透明 + 边缘高光」近似玻璃质感为度，不追求物理级折射仿真

#### Windows（适配 Windows 11 Fluent / Mica 风格）

- **窗口层**：Tauri `windowEffects` 启用 `mica`（Win11 材质，窗体透出桌面壁纸微染）；WebView2 (Chromium) 完整支持 `backdrop-filter`
- **控件**：WinUI 3 规范——控件圆角 8px（比 mac 更收敛）、强调色 `#0067C0`（Windows 11 system accent）系；弹层用亚克力质感（blur + 半透明 + 细边）
- **字体栈**：`Segoe UI Variable` 优先，回退现有栈；mac 端 `-apple-system` 已就位

#### 跨平台一致性

双平台共用同一套 CSS 变量与组件尺寸体系（当前已建立），仅"材质与圆角"按平台差异注入（构建期或运行时按 `platform()` 挂 class），保证一套代码两种原生观感；明暗主题沿用现有三态切换，玻璃/云母材质随主题切换基底色。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 分类自由输入导致口径不一（"高数"vs"高等数学"） | 下拉建议优先 + 输入历史去重提示；AI 打标不受影响（目录约束） |
| 职业考试目录专业性 | 种子目录标注来源与免责，开放社区 PR 扩充 |
| 大学生/考证人群对"家长代管"叙事无感 | README 与文案改为"学习者自助管理"中性表述（随一期落地） |
| 间隔重复算法调参 | 三期先上固定间隔（1/3/7/15 天），SM-2 权重后续迭代 |

## 7. 一期工作量评估

- 数据迁移（stage + qtype 双列）+ Rust API（normalize/筛选/导出）适配：1 天
- 前端录入/筛选/分析联动改造：1.5 天
- **题型统计**：词表联动 + AI 识别落库（split-check/tag 升级）+ 柱状/饼图 + 点击下钻 + 历史数据批量补标：2 天
- **知识点统计增强**：掌握状态加权口径 + 微型堆叠条：0.5 天
- catalog 种子 + AI prompt 适配 + 示例数据：0.5 天
