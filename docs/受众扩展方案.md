# 错题集 · 受众扩展可行性方案（v1.0）

> 日期：2026-10-10　状态：设计稿（待确认后实施）
> 目标：把产品从「高中以下学生」扩展到**中小学生、大学生、职业考试人员**（如中级会计师、法考、教资、公务员、考研）。

## 3. 数据模型设计（学段 Stage 模型）

### 3.1 现状与问题

当前 `questions` 表：`grade`（枚举 一年级~高三）、`term`（上/下）、`subject`（9 科）——分类维度与取值都被 K12 绑死；`catalog.json` 只覆盖小学语数英 + 初中数学。

### 3.2 目标模型（向后兼容，一次迁移）

```
questions 表新增：
  stage TEXT NOT NULL DEFAULT ''      -- 学段：小学/初中/高中/大学/职业考试/其他

grade 字段语义升级为「分类一」（不改列名，零迁移成本）：
  小学/初中/高中 → 年级（沿用现有取值）
  大学           → 课程名（高等数学、线性代数、概率论与数理统计、大学英语…支持自由输入）
  职业考试       → 考试项目（中级会计、法考、教资、公务员、考研…支持自由输入）

subject 字段语义为「分类二」：
  K12 → 9 科不变
  大学 → 章节（自由输入 + 常见建议）
  职业考试 → 科目（中级会计实务/财务管理/经济法…按考试项目联动）

term 字段：仅 stage ∈ {小学, 初中, 高中} 时 UI 显示；大学/职业考试隐藏（存空）
```

迁移：`ALTER TABLE questions ADD COLUMN stage TEXT NOT NULL DEFAULT ''` + 按 grade 回填（一~九年级→小学/初中，高一~高三→高中；空 grade 视为其他）。旧数据零破坏；导出/导入 JSON 同步带 stage。

### 3.3 知识点目录扩展（catalog.json 种子）

| 学段 | 科目/项目 | 条目内容（示例） |
| --- | --- | --- |

| 大学 | 线性代数 | 行列式、矩阵、向量组、线性方程组、特征值与特征向量、二次型 |
| 大学 | 概率论 | 随机事件、一维随机变量、多维随机变量、数字特征、大数定律、数理统计基础 |
| 大学 | 大学英语（四六级） | 词汇、长难句、听力、阅读、翻译、写作 |
| 职业考试 | 中级会计·中级会计实务 | 存货、固定资产、无形资产、投资性房地产、长期股权投资、所得税、合并报表… |
| 职业考试 | 中级会计·财务管理 | 财务管理总论、资金时间价值、风险与收益、筹资管理、投资管理、营运资金管理、成本管理 |
| 职业考试 | 中级会计·经济法 | 总论、公司法、合伙企业法、金融法律制度、合同法律制度、增值税、企业所得税 |

| 职业考试 | 教资（科目二） | 教育基础、学生指导、班级管理、学科知识、教学设计、教学实施、教学评价 |
| 职业考试 | 公务员·行测 | 政治理论、常识判断、言语理解与表达、数量关系、判断推理、资料分析 |
| 职业考试 | 考研政治 | 马原、毛中特、史纲、思修法基、形势与政策 |

目录 JSON 结构升级：`{stage, grade, term?, subject, points[]}`（term 可空表示不适用）；**标注"种子目录，欢迎社区扩充"**，设置页开放自定义编辑入口（三期）。

### 3.4 AI 打标适配

`/api/ai/tag` 入参加 `stage`；prompt 按学段变化：
- K12：沿用现有"从年级×学期×科目目录中选"
- 大学：从「课程×章节」目录选，标签粒度=章节知识点
- 职业考试：从「考试项目×科目」目录选，标签粒度=考点（如"长期股权投资"）

## 5. UI 设计（线框描述）

### 5.1 录入页（改动核心）

```
┌ 录入题目 ────────────────────────────────────────┐
│ 学段: [小学 ▾]   ← 新增顶部选择器，默认记住上次   │
│ ┌─ 依学段联动 ────────────────────────────────┐ │
│ │ 小学/初中/高中: 年级[▾] 学期[上/下] 科目[▾]  │ │
│ │ 大学:          课程[高数▾可输] 章节[可输]    │ │
│ │ 职业考试:      考试[中级会计▾可输] 科目[实务▾]│ │
│ └──────────────────────────────────────────────┘ │
│ 上传: [PDF/Word/图片 拖拽区]（本次已实现）          │
│ …（其余不变）                                      │
```

### 5.2 错题集筛选区

学段选择器置于筛选区首位；选择「大学/职业考试」时隐藏学期筛选，分类一筛选 label 随之变为「课程/考试项目」。

### 5.3 知识点分析页

条形图按学段分组 tab（避免不同学段知识点混排）；职业考试学段附"距考试天数"倒计时入口（可选，三期）。

### 5.4 视觉

沿用现有浅色主题 + 本次已交付的暗色主题；学段选择器、条目 chip 复用现有组件风格，不引入新组件体系。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 分类自由输入导致口径不一（"高数"vs"高等数学"） | 下拉建议优先 + 输入历史去重提示；AI 打标不受影响（目录约束） |
| 职业考试目录专业性 | 种子目录标注来源与免责，开放社区 PR 扩充 |
| 大学生/考证人群对"家长代管"叙事无感 | README 与文案改为"学习者自助管理"中性表述（随一期落地） |
| 间隔重复算法调参 | 三期先上固定间隔（1/3/7/15 天），SM-2 权重后续迭代 |

## 7. 一期工作量评估

- 前端录入/筛选/分析联动改造：1.5 天
- catalog 种子 + AI prompt 适配 + 示例数据：0.5 天
- 合计约 **3 个工作日**，无架构变更。
