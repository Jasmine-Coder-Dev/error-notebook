```
曝光（发帖/搜索）→ 点击（标题+首图）→ 了解（README）→ 下载试用 → Star/传播
```

| 环节 | 现状 | 行动 |

| 搜索曝光 | ✅ Topics 已设（tauri/rust/education/sm2…13 个） | 定期发版维持 Release 活跃度 |

## 三、渠道与现成文案

### A 类：开发者社区（Star 主力来源）

**1. V2EX「分享创造」**（首推，中文独立开发圣地）
> 标题：`[分享创造] 给娃做了款本地错题本 App：试卷拍照→AI 打标→按记忆曲线复习，Rust+Tauri 开源`
>
> 正文：
> ```
> 孩子每次考试的错题散在卷子里，手工抄题太费妈，市面上的错题 App 又强推云账号和订阅。于是写了这款：
> • 试卷 PDF/Word/照片上传 → 自动切题 → 勾选错题入库
> • AI 打知识点标签（GLM/DeepSeek/Kimi/Qwen 自配 Key，可选编程套餐）
> • 按 SM-2 记忆曲线自动安排重做，三键评分（忘了/想起来/很轻松）
> • 学情分析：题型统计、知识图谱、薄弱点一键出卷打印
> • 数据 100% 本地（SQLite），无账号无云端，macOS/Windows 双端
> 技术：Tauri 2 + Rust 内嵌 axum 后端，安装包 4~6MB，启动 0.4 秒。
> GitHub：github.com/Jasmine-Coder-Dev/error-notebook （MIT，求 Star 支持）
> ```

**2. HelloGitHub**（月刊收录，长尾流量大）
> 投稿地址 hellogithub.com，按模板填：项目名/地址/简介（100 字内）/截图。简介建议：
> `面向家长与学生的本地错题管理工具：试卷拍照自动切题、AI 知识点打标、SM-2 间隔重复复习、薄弱点组卷打印。数据全本地，Rust+Tauri，MIT 开源。`

**3. 掘金 / CSDN**（技术向软文）
> 标题方向：《我用 Rust + Tauri 给娃写了个错题本：0.4s 启动、4MB 安装包、SM-2 复习引擎》
> 内容结构：痛点 → 功能演示（GIF）→ 架构（Rust 内嵌 axum + 逐字段对拍测试）→ 数据安全设计 → 开源地址。掘金标签：`Rust` `Tauri` `开源` `教育`。

**4. 开源中国（oschina）+ Gitee 镜像**
> Gitee 建镜像仓库（国内访问加速，README 顶部加 Gitee 地址）；oschina 发布开源软件条目。

**5. Reddit**（英语区试水）
> r/selfhosted 或 r/Chinese：`[OC] ErrorNotebook – local-first mistake notebook for students: photo→AI tagging→SM-2 review, Rust/Tauri, MIT`

### B 类：家长/教育社群（真实用户来源，Star 间接增长）

**6. 小红书 / 知乎**（家长聚集地，转化极高）
> 标题方向：`发现了一个免费的错题整理神器｜拍照自动收录还能自动安排复习`
> 正文口吻：家长视角写使用场景（"期末前直接把薄弱知识点生成练习卷打印"），结尾提"开发者开源免费，GitHub 搜 error-notebook"。**不放技术栈**。

**7. 什么值得买 / 家长帮论坛**：发"免费软件"向体验帖。

### C 类：github 站内运营

- **Releases 保持节奏**：每 2~4 周一个版本（哪怕小改进），Release 会被 Watch 用户扩散
- **Good first issue**：标记"知识点目录扩充"类 issue（`server/catalog.json` PR 即可参与），降低贡献门槛
- **Awesome 列表 PR**：搜 awesome-education / awesome-tauri / awesome-chinese 列表提 PR 收录
- **回复时效**：Issue/Discussion 24 小时内回复（star 转化关键）
